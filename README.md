# Buildicy Team Hub

Build a premium, minimalist light-theme web application called Buildicy Team Hub.

Use my attached UI reference as the primary design inspiration. Follow its layout style, spacious composition, rounded cards, clean typography, soft grey surfaces and minimal sidebar navigation.

Brand: Buildicy — use our purple, white and subtle black colour palette. Purple should be the primary accent.

Build these screens:

Founder Dashboard — team performance, lead statistics, recent activity and follow-ups.

Member Dashboard — personal leads, assignments and daily activity.

Leads — searchable lead table, status badges, filters and add-lead form.

Lead Details — contact information, status updates, activity timeline and dedicated discussion.

Team Chat — group chat and private messaging interface.

Notifications and Team Management.

Design requirements:

Premium SaaS quality, not a generic admin template.

Minimal light theme with subtle shadows and borders.

Elegant purple accents, clean icons and consistent spacing.

Responsive desktop and mobile layouts.

Interactive navigation, buttons, modals, tabs and dropdowns.

Use realistic mock data.

Important: Build ONLY the frontend UI/UX using mock data. No backend, database, authentication integration or API development. Keep the components modular and the code clean so we can connect our own backend later.

Make the entire application feel like a polished, production-ready SaaS product.
